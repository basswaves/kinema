# Code of conduct

This project adopts the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in full.
Rather than restate it here and risk drifting from it, this file records what it
means in practice for a project this size.

## The short version

Be decent to people. Assume the person you are replying to is trying to help.

Harassment, personal attacks, demeaning comments, and unwelcome attention are
not tolerated, in issues, pull requests, commit messages or anywhere else this
project happens.

## What is specifically welcome

- **Bug reports that turn out to be your own setup.** Most first reports here
  will be a missing ffmpeg, a wrong path or a share that went away. Finding that
  out is a documentation bug, not a waste of anyone's time.
- **Disagreeing with a settled decision**, if you say which one and why. The
  reasoning is written down precisely so it can be argued with.
- **"I don't understand what this setting does."** That is a report about the
  interface, and a useful one — the app was written by someone who already knew
  the answer.

## What is not

- Demanding free support, or a fix, on any timescale. This is one person's hobby
  project, given away.
- Reopening a settled decision by repetition rather than by argument.
- Piracy talk. Kinema plays files you already have; where they came from is not
  a topic for this repository, and issues about acquiring media will be closed.

## Enforcement

Report anything that needs attention by opening an issue, or privately via
GitHub's [private vulnerability
reporting](https://github.com/Basswaves/kinema/security/advisories/new) if it
should not be public.

The maintainer will act as they see fit, up to and including blocking accounts.
There is no committee and no appeals process — it is one person reading.
